# Go-Admin 轻量后台管理系统 - 项目总览

## 项目定位

构建一个**轻量简洁**的后台管理系统，采用前后端分离架构，具备完整的 RBAC 权限管理、系统监控和代码生成能力。

## 核心功能模块

```
go-admin
├── 认证管理
│   ├── 登录/登出
│   ├── JWT Token 无感刷新
│   └── 图形验证码
├── 系统管理
│   ├── 用户管理（CRUD）
│   ├── 角色管理（CRUD）
│   ├── 菜单管理（CRUD）
│   └── 部门管理（CRUD）
├── 权限管理
│   ├── 菜单权限
│   ├── 按钮权限
│   └── 数据权限（全部/本部门/本部门及下级/仅本人/自定义）
├── 系统监控
│   ├── 运行环境监控（CPU/内存/磁盘/Go运行时）
│   ├── 操作日志（中间件自动记录）
│   ├── 登录日志
│   └── 日志清理策略
└── 代码生成
    ├── 在线配置表和字段
    ├── 一键生成前后端代码
    └── 代码下载
```

## 架构设计原则

1. **轻量至上**：不引入不必要的依赖，保持项目简洁
2. **按层分目录**：controller / service / repository / model 清晰分层
3. **接口抽象**：数据库层抽象接口，便于后续扩展多数据库
4. **代码生成统一**：生成的代码风格与手写代码完全一致
5. **前后端分离**：独立开发、独立部署，Nginx 反向代理
6. **表名可配置前缀**：通过 `table_prefix` 配置项统一管理表名前缀（如 `xy_`），便于多项目共用数据库
7. **数据安全**：密码 bcrypt 加密存储，敏感字段（手机号、邮箱等）API 响应自动脱敏
